## 纸上赶稿（同人制品 DDL 日历）

主催单人使用的同人制品赶稿与参展交付日期规划工具。以活动收货 DDL 为终点，倒排创作、约稿、下印与物流节点；日历分为「全部 / 主催 / 我的」，分别展示制品 DDL、催稿提醒与本人每日进度。
