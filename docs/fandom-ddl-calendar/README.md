# 纸上赶稿 · 需求与产品逻辑

这是「纸上赶稿」同人制品 DDL 倒推日历的独立文档目录。**仅主催使用**，其他参与者的信息由主催录入；项目不包括销售、库存和经营管理。

- [排程引擎技术研究 v0.1](SCHEDULING_ENGINE_RESEARCH_v0.1.md) — P0 日期与依赖修正：倒排最晚允许日、顺推预计完成日、实际历史、约定交稿、延期诊断与 17 项独立测试结果。
