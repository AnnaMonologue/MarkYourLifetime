## 纸上赶稿（同人制品 DDL 日历）

主催单人使用的同人制品赶稿与参展交付日期规划工具。以活动收货 DDL 倒排创作、约稿、下印与物流；**单一赶稿日历**汇总 DDL、节点、提醒和个人任务，另设「我的进度」集中记录每日产出与用时。
