# 纸上赶稿 · 水墨冷峻 UI（v0.9 视觉实验）

以 v0.8 Alpha 为基础的**纯视觉改版**。新的 `index.html` 是完整的离线单文件应用；页面业务逻辑、排程、进度和提醒的 JavaScript 没有变动，仍可直接本地打开。

## 设计

- 背景：宣纸白、浅墨冷灰、轻微纸感纹理，不使用大面积黑底
- 标题：系统宋体系列与克制的留白；方形朱印作为识别标记
- 交互：直角卡片、极细边框、深墨色小按钮；严肃、安静的页面层次
- 日历语义色：朱砂红（收货 DDL）、冷蓝灰（交稿/下印）、黄褐（提醒）、青墨绿（本人工作）

## 文件

- [index.html](index.html) — 可以直接保存、双击打开的完整网页
- [ink-theme.css](ink-theme.css) — 独立 CSS 主题覆盖层，方便后续调整

测试：已用 Chromium/Playwright 检查 1440px 桌面和 390px 手机端的基本交互，包括日历筛选、制品导航、进度录入与弹窗。与 v0.8 内嵌 JS 的文本已核对完全一致。此测试**不代表**全部极端业务场景都已验收。

范围不变：本地单人使用；不增加自动催稿消息、推送、账号、销售或库存，也不提供旧版数据迁移功能。
