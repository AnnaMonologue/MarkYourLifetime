# 纸上赶稿 v0.6 Alpha

独立的同人制品 DDL 日历网页原型，**只有主催本人操作**。外部作者、画师的进度由主催自行登记；提醒只在网页里显示，不向任何人发送消息或系统推送。

## 打开
下载并在浏览器打开 [index.html](index.html)。无需注册、联网或安装。新数据保存在浏览器本地存储 `zhishang-fandom-ddl-v06-new`，从零开始使用；不提供旧数据迁移或导入。本版可**导出**当前 JSON 供自行备份。

## 页面
- **赶稿日历**：一张日历呈现全部事项；红色=收货 DDL、蓝色=交稿/下印节点、黄色=提前提醒、绿色=自己的每日任务。月格超出三项时可点 `+N` 看当日完整清单，不再出现三个筛选页或日历外重复的当日列表。
- **我的进度**：当天本人需要做的工作、可手动输入的实际新增量与用时、最近进度；旁边是当前仍需处理的催稿/验收提醒及未来 14 天节点。提醒不会被误认为已完成，也不会发送给画师。
- **我的制品**：左侧主导航、第二列制品列表、右侧制品详情；手机端第二列改成水平切换标签。
- **参展活动**：第二列活动列表、右侧当前活动及其关联制品。

## 排程说明
保留 P0 双向排程（最晚允许日期 vs 最新预测）、原计划基线、交稿承诺与 P1 联系/返修状态。新建制品增加可见的「寄出前预留（天）」。未录入足够预计工期时，部分日期仍只是临时估算；务必核对印厂实际工期、物流与收货规定。

## 验证
通过 Chromium/Playwright 测试：三种原日历内容合并、日期详情、记录新增量和用时后留在进度页、提醒处理与交稿状态互不覆盖、两级制品及活动导航、手机布局、没有旧数据导入入口。测试脚本随下载 ZIP 提供。

## 范围边界
不做多人账号、经营、销售、库存、旧版本迁移、自动发送催稿消息、向任何人推送通知。此版本仍是 Alpha，尚未通过真实生产场景的全面验收。
