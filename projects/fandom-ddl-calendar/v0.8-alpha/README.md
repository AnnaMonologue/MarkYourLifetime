# 纸上赶稿 v0.8 Alpha

这是主催单人使用的同人制品 DDL 倒排与赶稿记录网页。直接下载并打开 [index.html](index.html)，无需账号、网络或安装。

v0.8 独立使用浏览器存储键 `zhishang-fandom-ddl-v08-new`，**从零录入**，不会覆盖 v0.7 数据，也不提供旧版迁移或导入。支持导出当前项目 JSON 留档，但当前网页没有导回功能。

## 功能

- 赶稿日历可按 **全部／主催／我的** 筛选。红色收货 DDL、蓝色交稿／下印、黄色提前提醒、绿色本人每日工作。
- **我的进度**列出当天需要完成的本人工作，包括逾期仍未完成的项目；可手工填写日期、实际产出、用时和完成状态。
- **我的制品**与**参展活动**均保留两列导航。五种制品模板支持多条并行工作路线。
- 催稿状态、验收、返修等仅供自己记录，**不会自动给画师发消息，也没有推送通知**。
- 改收货 DDL 前预览关联制品的关键日期变动；物流工序固定为下印末项。
- 逐张画稿支持补录有日期的草稿/上色/细化完成，手工确认和赶稿日志互不覆盖。
